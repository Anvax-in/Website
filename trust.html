02 · Defence-in-depth

Eight layers between the request and the data.

Each layer addresses a named threat. Compromise of any one layer does not yield cross-tenant data. The app DB role cannot bypass RLS even if the ORM is exploited.

# Layer Control Threat addressed
L1 Transport TLS 1.3 mandatory · HSTS preload Eavesdropping · MITM
L2 AuthN JWT validation · Argon2id passwords · Google OAuth · session bound to tenant Credential stuffing · session hijacking
L3 AuthZ Tenant scope injected by middleware on every request · Pydantic boundary validation Cross-tenant request forgery
L4 DB role demotion SET LOCAL ROLE anvax_app · no superuser · cannot bypass RLS Privilege escalation via ORM bug
L5 Row-Level Security Postgres RLS FORCE with USING (read) + WITH CHECK (write) on every customer table Cross-tenant data read / write
L6 Search-layer DLS OpenSearch Document-Level Security enforces tenant_id independently of the app Cross-tenant retrieval via compromised search credential
L7 Encryption at rest Per-tenant DEK (HKDF-derived) · AES-256-GCM on PII + OAuth tokens DB dump exposure
L8 Audit chain Append-only audit_log + immutable inference_traces · SHA-256 chained · UPDATE/DELETE blocked by DDL trigger Tampering · repudiation

05 · DPDP · CERT-In · RBI IT · IT Act

The other four frameworks your auditor will ask about.

Anvax is DPDP-aware today. CERT-In 6-hour incident reporting is wired into product. RBI IT Framework and IT Act intermediary obligations are satisfied by the same audit chain that backs FREE-AI R23.

Framework Requirement Implementation
DPDP Act 2023
§8 security safeguards		 Reasonable security safeguards for personal data — encryption, access control, logging, breach reporting. Per-tenant AES-256-GCM DEK · RLS · chained audit log · DPDP self-attestation API + checklist UI. Consent ledger and right-to-erasure on roadmap.
CERT-In 2022
§4 incident reporting		 Notification of in-scope cyber incidents within 6 hours of awareness. POST /compliance/incidents auto-computes cert_in_report_due = created_at + 6h for P1/P2 · typed export to the CERT-In format.
RBI IT Framework
Master Direction on IT Governance		 Tamper-evident logging · RBAC · encryption · segregation of duties for production. Chained-hash tamper-evident audit log · RBAC + tenant scoping · AES-256-GCM at rest · production change control via PR + approval gate.
IT Act 2000
Intermediary obligations		 Preservation of access logs · evidence handling · production change control. Same audit log + access controls satisfy the preservation requirement; exports are typed and signed.
06 · Engineering posture

The boring things, done.

Most AI-platform incidents are not novel — they're SQL injection, secret in a log line, a migration rolled back at 2am. Anvax's posture is engineered for the boring failure modes first.

82.6%
Test coverage

CI gate at 80%. Failing builds do not merge. Coverage tracked per package.

strict
Type checking

mypy --strict on Python, tsc --strict on TypeScript. CI-gated; no any escapes review.

forward-only
Migrations

Alembic, forward-only. Schema changes deploy with the code; no "manually run this SQL in prod" steps.

env / KMS
Secrets

Secrets via env + KMS, never in repo. Argon2id passwords. Audit on every secret access.

zero
f-string SQL

Parameterised queries only. grep '"f"' src/ for SQL strings is a CI failure.

Temporal
Workflows

Durable workflows on Temporal. Resumable across pod restarts and across days; full execution history retained.

tabular
Numerics

Tabular-nums in every UI. Indian numbering on rupee values. Audit log times in IST.

2 reviewers
Production change

Two-reviewer rule for production-touching PRs. Privileged actions require break-glass with audit.
