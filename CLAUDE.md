# Anvax website — working notes

Next.js 15 (App Router) · React 18 · CSS Modules · TypeScript. No Tailwind, no
CSS-in-JS. Deploys to Vercel from `main`.

```
src/app/              routes
src/components/       sections/ layout/ ui/ blog/
src/pages/*.module.css   page-level styles (not the pages router)
src/styles/tokens.css    design tokens — the single source of colour/size/space
content/blog/*.md     posts
docs/redesign-spec/   GENERATED design spec — see below
```

---

## The one rule that matters

**`public/redesign/index.html` is not HTML. Never copy markup out of it.**

It is a Claude Design canvas artboard. It contains a template language that only
its own runtime understands:

| In the file | What it is |
|---|---|
| `<sc-for list="{{ items }}" as="m">` | loop directive |
| `<sc-if value="{{ wide }}">` | conditional |
| `{{ navGap }}`, `{{ ctaHero }}` | data bindings |
| `style-hover="…"` | canvas-only hover attribute |
| `class Component extends DCLogic` | canvas component state |

It also has 419 inline `style=` attributes, 3 CSS classes, and 2 media queries —
both of them `!important` hacks. Pasting any of it into a `.tsx` throws **no
error** and renders wrong. A previous migration attempt was lost this way.

**Port from `docs/redesign-spec/` instead.** It is generated by
`scripts/proto-extract.mjs`, which runs the real canvas runtime in headless
Chromium and serialises the result:

```
docs/redesign-spec/shots/desktop-NN.png    what the block must LOOK like
docs/redesign-spec/shots/mobile-NN.png     at 600px
docs/redesign-spec/html/desktop/NN-*.html  flattened DOM — real values to read off
docs/redesign-spec/hover.json              the 20 hover rules
docs/redesign-spec/report.json             block inventory
```

Regenerate with `node scripts/proto-extract.mjs public/redesign docs/redesign-spec`
(needs `playwright`, `react`, `@fontsource/archivo` — see the script header).
Never hand-edit the spec.

## Porting a section

1. Look at `shots/desktop-NN.png`. That is the target.
2. Read structure and values off `html/desktop/NN-*.html`.
3. Write `SectionName.tsx` + `SectionName.module.css` by hand. Inline styles
   become class rules.
4. **Write the breakpoints yourself**, against `shots/mobile-NN.png`. They do not
   exist in the canvas — it branches in JavaScript (`wide >= 820`,
   `roomy >= 1140`) and only the nav uses it. Every other block is byte-identical
   at 1440 and 600. Do not go looking for mobile rules that were never written.
5. Pull hover states from `hover.json` into real `:hover` rules.
6. Verify (below).

## House rules

- **Tokens only.** No raw hex, rgb, or px colour in any `*.module.css`. If a
  value is missing, add it to `tokens.css` rather than inlining it.
- **Square corners.** `--radius-*` is `0` by design, except `--radius-chip` (4px,
  inline mono chips) and `--radius-pill`. Do not add `border-radius` to
  components. `50%` for actual circles is fine.
- **Primary CTA is blue** — `var(--cta)`. Note `--accent` is still charcoal, so
  `variant="accent"` buttons look stale next to primary ones; prefer `primary`.
- **`url()` belongs in `*.module.css`, never in `tokens.css`.** Next's global-CSS
  loader resolves `url()` at build time and fails on `/public` paths. The lattice
  texture is referenced directly as `url('/assets/lattice.svg')` in component
  modules for this reason.
- **Watch for `*/` inside CSS comments.** A path like
  `anvax-design-system-*/tokens/` in a comment closes it early and corrupts the
  whole file; PostCSS then reports a bogus error dozens of lines later.
- **No new npm dependencies** without a clear reason.
- Archivo is loaded by `next/font/google` in `layout.tsx` as `--font-sans`.

## Verifying

```bash
npx tsc --noEmit     # must be 0 errors
npm run build        # must pass
npm run dev          # then compare localhost:3000 against docs/redesign-spec/shots/
```

Compare at **1440 and 600** every time. Most regressions here are mobile-only,
because the mobile layout is being invented rather than ported.
